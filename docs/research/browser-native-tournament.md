# Browser versus native bot tournament

Rules grounding: canonical [computer rivals](../../prototypes/galactic-reach/rulebook.html#computer-rivals), [rival planning](../../prototypes/galactic-reach/rulebook.html#rival-planning), [resources](../../prototypes/galactic-reach/rulebook.html#resources), [combat](../../prototypes/galactic-reach/rulebook.html#combat) and [victory](../../prototypes/galactic-reach/rulebook.html#victory). Research tooling changes no costs, legal actions, information, scoring, default opponents or saved games.

Freeze current main's browser engine/adapter and native policies by source and executable hashes. MaxBot has no native counterpart and is excluded from the primary family comparison. No tuning after outcomes. Use ORCD compute nodes, normal finite market, 30 Prestige and 12 new fixed seeds: 2026111801 + 7919*i, i=0..11. The safety bound is 100 rounds/50,000 decisions; bounded games remain unfinished, with no invented winner.

Each game is a four-player free-for-all, with exactly two browser and two native bots. Bots do not receive team identities or additional cooperation. Family win share aggregates the winning seat's implementation; an evenly matched pair of implementations has a 50% reference share.

For each seed, run all 24 seat permutations of Market, Military, Economy and Expansion, each with all six ways to allocate the two browser seats: 1,728 mixed-role games. Also run all six allocations with each role occupying all four seats: 288 same-role games. Total 2,016. This crosses strategy with implementation instead of conflating a newer strategy with an implementation change. Seats, roles and opening maps/decks are matched; later random consumption may diverge naturally.

Primary outcome: browser/native win share in mixed-role games. Report same-role outcomes for each role separately, mean Prestige, scoring sources, completion and seat effects. Bootstrap entire seed blocks (10,000 replicates); do not treat correlated seat rotations as independent maps. Report unfinished-game counts and conservative family win bounds. Recommend a family only if the evidence supports it; role-specific reversals can justify retaining particular decision ideas in a future single implementation. No deletion, replacement, deployment or merger is part of this measurement PR.

Retain every full private game archive, RNG stream, action/event receipt, source, binary and configuration, including failed/interrupted attempts. Validate frozen source/executable identities, setup parity, state/counter/RNG hashes and every decision's resource conservation before interpreting rankings. A fresh legal-command port after each browser decision prevents stale native legal lists. Run mixed and same-role smoke games before production. Export complete data for later reanalysis; run production and trace audits on ORCD.

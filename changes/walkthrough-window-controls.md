title: Learn to play lights the button to use inside a window
---
In Learn to play, a note inside a window now lights the control to use next, as notes on the table already did: in a battle, Stay and fight, then the two tactics, then Commit; Continue on the battle report; Play Capacity Module, with the capacity split marked; and Done in the Trash window once the card is gone, instead of a note asking you to close the window. Inside a window the note is short (its title and one line) so the window's own controls stay in view, and every note, including one over a window the step does not use, offers Skip lesson. [Learn to play](rulebook.html#learn-to-play).

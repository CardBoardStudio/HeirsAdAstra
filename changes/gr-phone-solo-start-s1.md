title: A waiting room never offers a Start it cannot keep
---
A game for playing with others starts once a second person joins. Its older waiting room used to offer **Start** with only computer rivals seated, then refuse with a pairing notice. It now says that Start waits for someone, and offers **Play alone instead**; opening such a game from the game page reaches the same waiting screen as **Your tables**. [Playing with friends](rulebook.html#shared-tables).

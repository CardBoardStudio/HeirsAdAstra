title: Separate table setup from player and board screens
---
Create a table and choose where to play. Phones, desktops and personal tablets can use the full player view; a shared public board is optional and can join before or after the game starts. Closing that display leaves hosted play running. [Device setup](rulebook.html#phone-pairing) · [Public board](rulebook.html#public-board).
